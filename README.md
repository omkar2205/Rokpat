# Rok Pat — Portfolio Demo V1

A cinematic portfolio concept for Rok Pat, built as a static site for GitHub Pages.

## Direction

- Keep the existing Rok Pat identity understated and monochrome/sage rather than inventing a new brand.
- Let Rok's actual film, CGI and Unreal Engine work carry the visual impact.
- Editorial/cinematic layout instead of a conventional card-based portfolio.
- Two ways to browse work: **Cinema** and **Index**.
- Responsive from mobile through large desktop.
- Project imagery and video links reference Rok's public Behance / YouTube work for this demo.

- `script.js`
